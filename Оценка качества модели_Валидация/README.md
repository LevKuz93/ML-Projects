# Machine Learning Portfolio: Model Evaluation, Validation & Optimization


Репозиторий посвящен глубокому изучению схем валидации, методов оптимизации гиперпараметров, алгоритмов отбора признаков и защите моделей от утечки данных (*Data Leakage*). 

Практическая часть проекта реализована на основе конкурса Kaggle: **«Two Sigma Connect: Rental Listing Inquiries»** (предсказание популярности объявлений об аренде квартир в Нью-Йорке на основе данных [renthop.com](https://renthop.com)).

##  Глава I. Теория (Theory)

### 1. Метод «исключения одного элемента» (Leave-One-Out Cross-Validation / LOOCV)
Это предельный случай $K$-Fold кросс-валидации, где $K = N$ ($N$ — общее число объектов в выборке). На каждой итерации модель обучается на $N-1$ объектах, а тестируется на одном оставшемся.
* **Сильные стороны:** Максимально возможный объем данных для обучения на каждом шаге; детерминированность (нет случайности разбиения).
* **Ограничения:** Экстремально высокая вычислительная сложность при больших $N$; высокие дисперсионные оценки качества, так как обучающие выборки на каждом шаге сильно скоррелированы между собой.

### 2. Алгоритмы оптимизации гиперпараметров
* **Grid Search (Поиск по сетке):** Полный перебор фиксированного набора параметров. Гарантированно находит лучший вариант из заданной сетки, но неэффективен и занимает много времени на больших пространствах поиска.
* **Random Search (Случайный поиск):** Выбирает случайные комбинации из распределений параметров. Быстрее находит близкое к оптимальному решение, так как не тратит ресурсы на перебор неважных гиперпараметров.
* **Байесовская оптимизация:** Строит суррогатную вероятностную модель зависимости целевой метрики от гиперпараметров. Выбирает следующую точку для проверки там, где ожидается улучшение (на основе баланса исследования новых областей и эксплуатации известных оптимумов).

### 3. Классификация методов отбора признаков (Feature Selection)
* **Filter Methods (Фильтрационные):** Оценивают каждый признак независимо от модели с помощью статистических тестов.
  * *Коэффициент Пирсона:* Измеряет силу линейной взаимосвязи между непрерывными переменными (от -1 до 1).
  * *Хи-квадрат ($chi^2$):* Проверяет независимость двух категориальных признаков на основе таблиц сопряженности.
* **Wrapper Methods (Оберточные):** Используют алгоритм машинного обучения как "черный ящик" для оценки подмножеств признаков (например, прямой/обратный перебор). Высокая точность, но медленная работа.
* **Embedded Methods (Встроенные):** Отбор происходит непосредственно во время обучения модели.
  * *Lasso ($L_1$-регуляризация):* Добавляет штраф за абсолютные значения весов $\lambda \sum \vert{}\theta_i\vert{}$. Из-за геометрии ограничений штрафа $L_1$ зануляет веса наименее информативных фичей, удаляя их из модели.
* **Advanced/Agnostic методы:**
  * *Permutation Importance (Значимость перестановок):* Измеряет, насколько ухудшается метрика модели, если случайным образом перемешать значения одного признака в валидационном датасете (разрушив его связь с таргетом).
  * *SHAP (SHapley Additive exPlanations):* Метод из теории игр, который рассчитывает вклад каждого признака в конкретное предсказание модели, обеспечивая локальную и глобальную интерпретируемость.

##  Глава II. Практическая реализация (Implementation Tasks)

### 1. Кастомные методы разбиения данных (Hold-out Splitting)
Реализованы с нуля на чистом Python/NumPy следующие функции:
* `split_train_test(data, test_size)` — Случайное разделение на 2 части по пропорции.
* `split_train_val_test(data, val_size, test_size)` — Случайное разделение на 3 части (Обучение / Валидация / Тест).
* `split_by_date(data, date_split)` — Разделение на 2 части по временной отсечке во избежание заглядывания в будущее.


> ** Что значит сделать процедуру детерминированной?** Это фиксация генератора случайных чисел (`random_state` или `np.random.seed`). Это гарантирует, что при каждом запуске программы разбиение данных будет идентичным. Критически важно для воспроизводимости экспериментов.

### 2. Собственные алгоритмы кросс-валидации (Cross-Validation)
Написаны генераторы индексов для фолдов:
* **K-Fold:** Классическое разбиение на $K$ случайных блоков.
* **Group K-Fold:** Гарантирует, что записи с одинаковыми идентификаторами (например, `manager_id` или `building_id`) не попадут одновременно в обучение и тест.
* **Stratified K-Fold:** Сохраняет баланс долей классов целевой переменной `interest_level` в каждом фолде.
* **Time Series Split:** Реализует валидацию на скользящем или расширяющемся временном окне на основе поля даты.

### 3. Эксперименты: Отбор признаков (Feature Selection Analysis)

1. **Lasso Weights:** Сортировка признаков по величине модулей весов модели.
2. **Missing/Correlation Filter:** Кастомный фильтр, отсекающий фичи с высоким процентом `NaN` и низкой корреляцией с таргетом.
3. **Permutation Importance:** Оценка стабильности модели при случайных перестановках значений.
4. **SHAP:** Ранжирование по среднему абсолютному значению Shapley values.

*В проекте содержится аналитическая таблица сравнения этих методов по **скорости работы, итоговому качеству (метрикам) и стабильности** выделенного подмножества.*

### 4. Оптимизация гиперпараметров (Hyperparameter Tuning)
Реализован подбор параметров `alpha` и `l1_ratio` для модели **ElasticNet**:
* Сравнение кастомных алгоритмов **Grid Search** и **Random Search** с аналогами из `scikit-learn`.
* Интеграция фреймворка **Optuna** для продвинутого поиска.
* Настройка работы Optuna поверх разработанных схем кросс-валидации для получения несмещенной оценки качества.
