# Machine Learning: Unsupervised Learning. Dimensionality Reduction


## Краткое описание проекта
Данный проект посвящен задачам обучения без учителя (*Unsupervised Learning*) с упором на современные и классические методы снижения размерности данных. 

В условиях отсутствия целевой переменной проект исследует подходы к сжатию признакового пространства, визуализации высокоразмерных структур, фильтрации шума и выделению скрытых сигналов на табличных данных, изображениях и видеопотоке.

---

## Цели проекта
* Получить глубокое понимание математических принципов и алгоритмов снижения размерности.
* Научиться применять методы сжатия признаков для оптимизации моделей машинного обучения на разреженных данных.
* Освоить практическое применение сингулярного разложения (SVD) для задач компьютерного зрения: сжатия изображений и динамического выделения фона на видео.

---

## Глава I. Базовые методы снижения размерности (Core Methods)

В рамках проекта подробно изучается математическая структура и область применения следующих фундаментальных алгоритмов:

### 1. Линейные методы и матричные факторизации
* **PCA (Principal Component Analysis / Метод главных компонент):** Линейное преобразование, которое проецирует данные на ортогональные направления максимальной дисперсии. Требует предварительного центрирования признаков.
* **SVD (Singular Value Decomposition / Сингулярное разложение):** Алгебраическая операция разложения любой матрицы данных $X$ на три составляющие:
  $$X = U \Sigma V^T$$
  Где $U$ и $V$ — ортогональные матрицы, а $\Sigma$ — диагональная матрица сингулярных значений. Применяется для получения низкоранговых приближений.
* **NMF (Non-Negative Matrix Factorization / Неотрицательная матричная факторизация):** Факторизация с ограничением неотрицательности элементов ($\ge 0$). Используется для интерпретируемого разложения данных на аддитивные составляющие («части целого»).

### 2. Методы многообразного обучения (Manifold Learning)
* **LLE (Locally Linear Embedding / Локально линейное вложение):** Нелинейный метод, который сохраняет локальную геометрию окрестностей, представляя каждую точку как линейную комбинацию её ближайших соседей.
* **t-SNE (t-Distributed Stochastic Neighbor Embedding):** Алгоритм стохастического вложения соседей, преобразующий расстояния между точками в условные вероятности. Идеален для визуализации сверхсложных нелинейных структур в 2D/3D пространстве.
* **UMAP (Uniform Manifold Approximation and Projection):** Современный масштабируемый метод, основанный на римановой геометрии и алгебраической топологии. В отличие от t-SNE, лучше сохраняет не только локальную, но и глобальную структуру данных при сжатии.

## Глава II. Практическая часть (Practice Pipeline)

### Использованные наборы данных (Datasets)
1. **Book Recommendation Dataset:** Данные взаимодействий пользователей с книгами для построения разреженных матриц и прогнозирования возраста.
2. **MNIST:** Классический датасет рукописных цифр ($28 \times 28$) для тестирования алгоритмов визуализации.
3. **Background Models Challenge (BMC 2012):** Видеозапись `Video_008.avi` с уличной камеры (из архива `bmc_real.zip`) для выделения фона.
4. **Facial Expression Dataset:** Набор изображений лиц с различными эмоциями (дополнительное задание).

### Реализованные шаги, инструменты и цели:

* **Классификация на разреженных признаках (Book Recommendations):**
  * *Реализация:* Построение разреженной матрицы взаимодействий пользователь-книга (`scipy.sparse`). Моделирование (Linear Models, Random Forest) для предсказания возраста пользователя напрямую и после сжатия через PCA / UMAP.
  * *Инструменты:* `scipy.sparse`, `sklearn.decomposition.PCA`, `umap-learn`.
  * *Суть и навыки:* Оценка влияния снижения размерности на скорость обучения (*fit time*) и итоговое качество моделей при работе с сильно разреженными данными.

* **Визуализация высокоразмерных структур (MNIST):**
  * *Реализация:* Вытягивание матриц изображений в векторы и сжатие до 2D пространства с помощью 6 методов: PCA, SVD, Randomized-SVD, t-SNE, UMAP и LLE.
  * *Инструменты:* `sklearn.manifold` (`TSNE`, `LocallyLinearEmbedding`), `umap`.
  * *Суть и навыки:* Разработка метрик качества кластеризации (оценка разделимости классов цифр) и визуальное сопоставление глобальных и локальных геометрических свойств методов.

* **Сжатие изображений через Низкоранговое приближение (SVD):**
  * *Реализация:* Разложение матрицы полутонового изображения через SVD. Восстановление картинки с использованием 10 различных рангов. Построение графика распределения объясненной дисперсии.
  * *Математический контекст:* Объясненная дисперсия показывает долю информации (энергии спектра сингулярных значений \(\sigma_i\)), удерживаемую первыми \(k\) компонентами:
    $$text{Explained Variance} = \frac{\sum_{i=1}^{k} \sigma_i^2}{\sum_{j=1}^{r} \sigma_j^2}$$
  * *Суть и навыки:* Анализ спектра сингулярных значений для определения минимального числа мод, необходимых для качественного сжатия без потери визуального восприятия.

* **Выделение фона на видео (Background Detection):**
  * *Реализация:* Конвертация кадров видео `Video_008.avi` в столбцы единой матрицы данных. Применение SVD для разделения видео на низкоранговую стабильную матрицу (статичный фон улицы) и разреженную матрицу отклонений (динамические объекты: машины, пешеходы).
  * *Суть и навыки:* Понимание SVD как инструмента фильтрации постоянного сигнала от динамического шума в видеопотоке.

* **Дополнительная задача (Facial Expression Latent Vector Math):**
  * *Реализация:* Обучение модели снижения размерности на изображениях лиц. Манипуляция латентными векторами (векторная арифметика в сжатом пространстве) для трансформации эмоций — превращение грустного лица в улыбающееся.

## Вывод (Summary)
Данный проект наглядно демонстрирует, как абстрактные методы линейной алгебры и топологии решают сложные прикладные задачи машинного обучения. Снижение размерности с помощью PCA и UMAP позволило радикально ускорить обучение моделей на гигантских разреженных матрицах книжных рекомендаций без критической потери качества. Практические эксперименты с SVD доказали эффективность низкоранговых приближений: алгоритм успешно справился как со сжатием статичной графики (MNIST, фотолинейки), так и со сложной задачей сегментации компьютерного зрения — полным отделением статичного фона от движущихся объектов на видео с реальных городских камер.
