# Linear Regression Model

## Обзор проекта (Overview)
Данный проект посвящен глубокому изучению и практическому применению задач обучения с учителем, а именно — линейных моделей регрессии. В рамках проекта исследуются проблемы переобучения (overfitting) и недообучения (underfitting), методы регуляризации, а также метрики оценки качества предсказаний.

Практическая часть проекта реализована на основе конкурса с платформы Kaggle: **«Two Sigma Connect: Rental Listing Inquiries»**. Цель — предсказать уровень популярности объявлений об аренде квартир в Нью-Йорке на основе их характеристик (цена, описание, количество комнат, фотографии и др.).

---

## Набор данных (Dataset)
*   **Источник данных:** Данные объявлений об аренде недвижимости в Нью-Йорке с сайта `renthop.com` (Kaggle Competition).
*   **Файлы:**
    *   `train.json` — обучающая выборка с целевой переменной.
    *   `test.json` — тестовая выборка для проверки качества модели.
*   **Целевая переменная (`interest_level`):** Уровень интереса пользователей к объявлению (определяется количеством запросов за время размещения).
*   **Ключевые признаки:** Количество спален/ванных комнат, стоимость аренды, текстовое описание, метаданные фотографий, географические координаты.

## Рабочий процесс проекта (Project Workflow)

### Часть 1. Теоретический фундамент (Theory & Analytics)
В ходе аналитического разбора были изучены и решены следующие задачи:
1. **Матричный вывод:** Выведено аналитическое решение задачи линейной регрессии через нормальное уравнение (Normal Equation) в векторно-матричной форме с использованием метода наименьших квадратов (МНК):

$$\theta=(X^TX)^{-1}X^Ty$$

Где $\theta$ — вектор оптимальных весов модели, $X$ — матрица признаков объектов, $y$ — вектор целевой переменной.

2. **Анализ регуляризации:** Исследованы изменения в аналитическом решении при добавлении $L_1$ (Lasso) и $L_2$ (Ridge) ограничений к функции потерь.
3. **Отбор признаков:** Математически обосновано, почему $L_1$-регуляризация (Lasso) зануляет веса наименее информативных признаков и используется для Feature Selection.
4. **Вероятностный подход:** Линейная регрессия рассмотрена с точки зрения теории вероятностей (в допущении нормального распределения шума и максимизации правдоподобия).

### Часть 2. Практическая реализация и Feature Engineering
1.  **Предобработка данных и нормализация:** Применение масштабирования признаков (Feature Scaling) для корректной работы градиентного спуска и регуляризаторов.
2.  **Трансформация целевой переменной:** Борьба со смещенными распределениями и «тяжелыми хвостами» с помощью логарифмирования (монотонные функции для улучшения качества подгонки модели).
3.  **Нелинейные зависимости:** Создание полиномиальных признаков (Polynomial Features вплоть до 10-й степени) для выявления сложных нелинейных связей при сохранении линейного алгоритма обучения.
4.  **Обучение моделей:** Построение и сравнение базовой линейной регрессии, а также моделей с регуляризацией:
    *   **Ridge Regression** $L_2$
    *   **Lasso Regression** $L_1$
    *   **ElasticNet** (комбинация $L_1$ и $L_2$)
5.  **Валидация и оценка качества:** Глубокий анализ предсказаний с использованием комплекса метрик регрессии.

## Метрики оценки качества (Evaluation Metrics)

Для всесторонней оценки построенных моделей и интерпретации ошибок использовались четыре ключевые метрики:

*   **MAE (Mean Absolute Error — Средняя абсолютная ошибка):** 
    Показывает среднее абсолютное отклонение предсказаний от реальных значений в тех же единицах измерения. Обладает высокой устойчивостью (робастностью) к аномалиям, не штрафуя модель за единичные крупные промахи так сильно, как квадратичные метрики.
*   **MSE (Mean Squared Error — Средняя квадратичная ошибка):** 
    За счет возведения разностей в квадрат сильнее штрафует модель за большие ошибки. Анализ MSE в сравнении с MAE использовался для детекции наличия редких, но критических выбросов в данных (например, аномально дорогих или дешевых квартир).
*   **RMSE (Root Mean Squared Error — Корень из средней квадратичной ошибки):** 
    Извлекает квадратный корень из MSE, возвращая ошибку к исходной размерности целевой переменной. Помогает более наглядно интерпретировать величину «штрафа» за крупные ошибки предсказания в контексте бизнес-задачи.
*   **R² (Coefficient of Determination — Коэффициент детерминации):** 
    Показывает долю дисперсии целевой переменной, объясненную моделью. Используется как универсальный индикатор качества: значение близкое к 1 говорит о высокой предсказательной силе, значение около 0 означает, что модель предсказывает на уровне среднего значения, а отрицательный $R^2$ сигнализирует о явном переобучении или некорректной структуре модели.

## Полученные ключевые навыки (Learning Takeaways)
*   **Глубокое понимание линейных моделей:** Умение математически выводить формулы и оптимизировать веса через градиентный спуск (Gradient Descent).
*   **Контроль переобучения:** Практические навыки борьбы с Overfitting с помощью настройки гиперпараметров регуляризации $\alpha$.
*   **Продвинутый Feature Engineering:** Генерирование полиномиальных признаков и трансформация распределений (log-transform) для «тяжелых хвостов».
*   **Валидация моделей:** Интерпретация различий между MAE, MSE и RMSE для оценки влияния шума и выбросов на итоговый скор.
